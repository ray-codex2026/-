# Mercado AI Studio

面向墨西哥 Mercado Libre 的中文商品内容工作台。Python + Streamlit + OpenAI + Pillow + SQLite。默认模拟模式，不需要密钥。每款输出8张编号图片、标题和包含5个章节的详情，审核后导出 SKU 文件夹 ZIP。

## Windows 安装和启动

1. 安装 **Python 3.11 或 3.12**（推荐3.12），勾选 Add Python to PATH。下载/克隆本仓库至可写目录。
2. 双击 `start_windows.bat`。首次安装依赖需要网络；脚本将创建 `.venv` 并启动浏览器界面。
3. 默认 mock 模式可完整演练上传、排队、审核、文案编辑和下载。模拟场景明确标注 MOCK，模拟文案含占位内容，不能直接上架。
4. 如浏览器未打开，按终端显示的本机地址访问。关闭终端停止应用；以后再次双击即可。

手动安装及验证（PowerShell）：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

Linux/macOS：`bash start.sh`。开发测试：`.venv/bin/python -m pytest -q`。

## API Key 配置

复制 `.env.example` 为 `.env`，在**本机文件中**填入 `OPENAI_API_KEY`；也可在启动进程前配置同名环境变量。不要发到聊天、不要提交 Git。`.env` 已被忽略。重启应用后在“API 设置”查看是否已配置，再选择 live。

默认文本模型 `gpt-4.1-mini`，图片编辑模型 `gpt-image-1`，可通过环境变量替换为支持相同接口的模型。真实模式使用 Chat Completions 多模态 JSON 输出、Images 编辑接口和 b64 图片响应。需要账户有对应模型和图片生成权限，可能需要组织验证；支持 HTTPS 出站 `api.openai.com`。API超时180秒，SDK自动重试关闭，防止模糊失败自动重复收费。429或网络失败进入失败状态，可在间隔后人工重试。

此交付通过模拟与假API响应测试，**未验证真实API账户、真实生成质量或Windows机器执行**。AI不能保证完全保真，所有输出必须人工审核。不得把模拟通过当作真实API验证。

## 操作流程

1. **商品上传**：一次选1–50款，每款多张 JPG/PNG。第1张提供完整、干净背景商品；第2张必须是同一商品的其他真实角度。最多10张/款、20MB/张、4000万像素/张。上传会去EXIF并规范化为PNG。
2. 填写真实名称、类别、颜色、材质、数量、包装内容、卖点、宽高和单位。填写用于图片07的已确认西班牙语短卖点；其他参数可填深度、尺码等。不得填猜测数值。名称等可用中文，真实API会生成西班牙语文案；图片卖点请自行核对翻译。
3. 商品可以先保存草稿，在商品管理补齐参数或替换整组照片；替换照片会清除旧生成内容并保留原图历史文件。点击确认真实参数、第二角度及已核对类目规则后才能生成。没有侧背面图或尺寸会明确阻止任务。
4. **API 设置**：选模式、保守单次费用预留、每日预算和间隔。**图片生成**多选商品，查看预估并勾选付费/模拟确认，再点击开始。
5. **任务进度**：10步=识别、文案、8图。串行请求限制并发为1，批次队列用于每日20–50款的操作规模；未做50款真实API吞吐压测，实际产能受接口速率、延迟与人工审核影响。可暂停、继续、失败重试、取消。暂停在当前请求结束后生效，执行中的任务需先暂停再取消。
6. **图片预览审核**：检查每图，单独重生成只删除该图缓存并重置其审核。真实场景图附视觉审核建议，审核建议不会自动批准。审核某张后可单张下载。
7. **标题和详情编辑**：检查墨西哥西班牙语、事实和标题长度，编辑保存并明确审核通过。
8. **批量下载**：仅列出8图及文案全部审核通过的商品。可单款、多款、600或1200、JPG或PNG导出。ZIP含01–08、titulo.txt、descripcion.txt及manifest.json。文件夹用安全SKU加ID后缀防碰撞，内部保存路径用ID避免SKU路径穿越。

## 八张图的实现与边界

| 编号 | 方式 | 需要注意 |
|---|---|---|
| 01 主图 | 原照片等比居中、白色留边 | 不自动抠图，原背景仍存在。请提供合规干净背景图，无水印。 |
| 02 家庭场景 | AI编辑，多张参考图约束 | 分类独立场景配置，须人工核对保真 |
| 03 第二场景 | AI编辑，区别于02的场景 | 人工检查场景差异与使用合理性 |
| 04 第三场景 | AI编辑，不同家庭构图 | 人工检查与02/03不重复 |
| 05 尺寸 | Pillow绘制西语宽高标注和尺寸线 | 数字来自用户，线为示意，须确认照片方向与实际宽高匹配 |
| 06 细节 | 原图中心60%真实裁切 | 不补画不可见细节；请确保第1张中央有可用细节，否则需更换参考图 |
| 07 卖点 | 原图合成确认过的西语短句 | 最多4行，不自动虚构性能和认证 |
| 08 其他角度 | 第2张真实照片等比处理 | 用户确认角度，人工检查与前图不重复 |

场景API原生1024×1024，导出默认600×600。1200版本会放大场景图，**不是原生1200高清细节**；本地图片以1200画布保存，但清晰度取决于原图。始终等比，不拉伸。

类别、标题字符上限和最低图片分辨率随 Mercado Libre 规则变化，本系统不抓取或认证平台规则；60字符仅为可编辑初始值，600像素不保证每个类目都接受。使用前在卖家后台核对当前类目图片、标题及禁用信息要求。系统不自动发布商品。

分类配置见 `mercado/content.py::CATEGORIES`，首版包含家具收纳、童装和厨房用品10个子类，场景提示分别定义，文案采用相应类别与用户事实驱动的统一5节结构。

## 费用、预算与缓存

- 金额统一USD，日界按UTC。默认图片请求预留0.25、文本/视觉0.05，仅为可修改保守占位估算，**不是官方价格**。
- 基础流程3次图片编辑、2次文本识别/文案、3次场景视觉审核；本地5张图无API费用。默认基础估算每款1.00 USD。模型用量、输入图、失败重试会影响真实费用。
- 每次真实请求先在SQLite事务内检查预算并预留额度。超预算拒绝下一请求。API usage原样保存；未知实际金额保持NULL，不伪造美元成本。
- “费用统计”按供应商账单手动对账，区分预估、未核对预留和已核对实际金额。超时可能已经收费，保留uncertain预留。请同时设置供应商消费限制，应用无法保证预留单价总能覆盖实际账单。
- 完成图片按商品/编号缓存。场景已生成但视觉审核失败时保留pending文件，重试只做审核。API返回前断线仍存在重复收费风险，重试前检查供应商记录。
- 同SKU不能重复入库；已有图片不允许全款重复排队。需要全款重做时，在管理页确认清除旧内容，保留历史和费用后重新排队。修改商品参数会撤销所有审核，修改后务必清除旧内容重新生成。

## 数据、恢复与运维

默认数据保存在 `data/studio.db` 和 `data/products/<内部ID>/`，可用 `MERCADO_DATA_DIR` 指定绝对路径。备份时先停止应用，再整体备份data。仅适用于可信人员的本机使用：没有用户登录或多租户隔离，不要直接暴露至公网。

后台线程按步骤保存状态，进程间文件锁防止两个应用同时调用API。应用停止后再次启动，在任务进度点“继续队列”。文件锁在进程退出后自动释放，无需删锁文件。重启会继续running/queued任务，paused需手动继续。Windows关闭进程可能中断请求，应先暂停并等待当前请求结束。

错误写入任务记录与日志表；不记录API异常原文、密钥或完整环境变量。识别发现资料冲突会停止；在任务页取消失败任务后，修正资料并重新生成。不确定的视觉审核仅作为建议，由人工决定是否通过。服务不自动推送GitHub，未包含GitHub凭据；项目目录可直接提交到所选仓库。

## 开发结构

```text
app.py                 中文九页界面
mercado/store.py        SQLite、参数入库、预算事务
mercado/content.py      分类模板、事实检查、OpenAI/模拟适配
mercado/imaging.py      等比处理、裁切、尺寸线、文字合成
mercado/engine.py       持久任务步骤、暂停恢复、缓存、调用费用
mercado/downloads.py    审核门槛与ZIP导出
requirements.txt       跨平台依赖
requirements-lock.txt  云环境已验证版本（Python3.12）
start_windows.bat       Windows一键安装启动
start.sh               Linux/macOS启动
.env.example           无密钥配置模板
tests/                 分阶段测试与界面冒烟
```

开发阶段与验证记录见 `VALIDATION.md`。
